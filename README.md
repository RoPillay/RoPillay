**By day I'm an AI Engineer at Colibri Group**, where I build Model Context Protocol tooling and an AI-native learning platform that author, grade, and coach with Claude, Gemini, OpenAI, and AWS Bedrock. ## Impact

**A 21-tool MCP server that ships whole course tracks** — built in TypeScript on Cloudflare Workers, paired with a Claude agent skill that authors, validates, and publishes LMS course tracks across Claude, Gemini, and OpenAI.

**An AI-native LMS, soft-launched internally** — co-developed learner, Course Studio, and admin portals (React, Cloudflare Workers, PostgreSQL) with behavioral analytics, and extended Rubi, an AWS Bedrock AI grader and lesson coach, with acceptance-criteria grading and in-module coaching.

**LLM answers checked against ground truth** — a Python evaluation framework that grades an analytics MCP against analyst-verified reference SQL using a separate-vendor LLM judge. A/B tested a unified MCP gateway at 1.6–2.7x token overhead with no accuracy loss.

**~64% of podiums predicted in a stochastic sport** — Plackett–Luce and two-stage XGBRanker models with walk-forward cross-validation, reaching Spearman ~0.69 on Formula 1 finishing order.

**10,000+ Monte Carlo race simulations** — lap-time variability, tire degradation, pit strategy, and race dynamics, extending toward a reinforcement learning framework for strategy optimization.

**R² up to 0.70 on song success** — a 5,700+ track Spotify/YouTube dataset with audio processing and MERT + lyric embeddings, modeled with XGBoost, CNN, and AST-embedding pipelines and deployed as an interactive Dash app.

## Selected work

**[Formula 1 Race Prediction](https://github.com/RoPillay/Formula1-Race-Prediction)** — ongoing UC Davis research: regularized Plackett–Luce and two-stage XGBRanker models over telemetry, qualifying, and race-context features, predicting ~64% of podium finishes with Spearman ~0.69.

**[F1 Race Simulator](https://github.com/RoPillay/f1-simulator)** — single- and multi-driver Monte Carlo simulation of tire degradation, pit strategy, and race interaction dynamics, with a reinforcement learning environment for strategy optimization.

**[Spotify–YouTube Music Prediction](https://github.com/RoPillay/Spotify-Youtube-Music-Prediction)** — capstone predicting song popularity and marketability from 5,700+ tracks; the final XGBoost model reached R² 0.66 on popularity and 0.70 on marketability, served through a Dash app with audio upload and similarity search.

**[F1 Data Insights Dashboard](https://github.com/RoPillay/F1-Data-Insights-Dashboard)** — a public Streamlit app on the FastF1 API: driver telemetry overlays, delta time, track speed heat maps, and Random Forest stint degradation across 2M+ data points.

**[Neural Activity-Based Behavior Prediction](https://github.com/RoPillay/Neural-Activity-Based-Behavior-Prediction)** — predicting mouse decisions from neural spike trains (Steinmetz et al., 2019) with logistic regression and random forests at 72% accuracy.

**[Property Interactive Dashboard](https://github.com/RoPillay/Property-Interactive-Dashboard)** — an R + Plotly + crosstalk dashboard linking a map, scatter plot, and searchable table across real estate in eight counties near Davis, CA.
